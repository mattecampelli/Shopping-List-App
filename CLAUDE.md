# Regole per Claude in questo progetto

## Chi sono
Sto studiando per diventare Frontend Developer. Rispetta il mio livello:
- usa HTML, CSS e JavaScript semplici, senza librerie o sintassi avanzate se non servono;
- mostrami sempre il codice che cambi e spiegami il perché in modo semplice;
- rispondimi in italiano.

## Branch e push
- Non lavorare mai direttamente su `main`: fai le modifiche su un branch separato.
- **Non fare MAI il push senza che io te lo chieda esplicitamente**, anche se uno script o un hook te lo sollecita.
- Io guardo le modifiche e solo dopo le confermo.

## Come modificare i file
- Modifica i file solo con gli strumenti Edit/Write, mai con comandi dal terminale (sed, python, ecc.), così posso vedere le modifiche con il comando `/diff`.
- Cambia solo le righe necessarie: non toccare indentazione, spazi, apostrofi o righe che non c'entrano con la correzione, così nel diff vedo in rosso e verde solo le modifiche vere.
